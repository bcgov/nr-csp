# CSP user manual: industry

This manual is for industry users of the Coast Selling Price system (CSP).
Companies that buy or sell logs on the coast report each log sale invoice to
the ministry. You send your invoices to CSP as an XML file, CSP checks them,
and ministry staff review each one. You log in with Business BCeID.

## How to read this manual

- **Menu paths** are written as **Group › Menu item**, for example
  **Submissions › Upload Submission**. The groups are in the left-hand menu.
- **On-screen labels** are in bold, exactly as CSP shows them.
- **The screenshots use sample data.** The people, companies, client numbers
  and invoices in them are made up.
