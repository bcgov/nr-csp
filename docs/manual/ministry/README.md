# CSP user manuals: ministry roles

This manual is for ministry staff who use the Coast Selling Price system
(CSP). CSP collects the coastal log sale invoices that sellers and buyers
report, electronically as XML files or entered by staff, and staff review and
approve them. CSP also holds the sort code and flat price conversion tables
and produces the CSP reports. You log in with IDIR. The manual covers your
role: what you see on screen and how to get a job done.

Each staff role has its own manual, and industry users have another.

## How to read this manual

- **Menu paths** are written as **Group › Menu item**, for example
  **Support › User manual**. The groups are in the left-hand menu.
- **On-screen labels** are in bold, exactly as CSP shows them.
- **You only see what your role allows.** If a menu item or button in this
  manual is missing or greyed out for you, your role doesn't grant it. See
  [Who can do what](08-who-can-do-what.md).
- **The screenshots use sample data.** The people, companies, client numbers
  and invoices in them are made up.
