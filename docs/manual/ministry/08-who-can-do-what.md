# 8. Who can do what

CSP has four staff roles, granted to your IDIR. Your profile shows your role.
If you hold more than one, you can do everything each one allows.

| Role | For |
|---|---|
| **Admin** | Everything, including changing the sort code and flat price conversion tables. |
| **Approver** | Entering, reviewing and deciding invoices, and reports. |
| **Data Entry** | Entering manual invoices and submitting them for review. |
| **Viewer** | Looking up invoices, submissions, tables and reports. |

## What each role can do

| Task | Admin | Approver | Data Entry | Viewer |
|---|---|---|---|---|
| Search invoices and open them | Yes | Yes | Yes | Yes |
| Inbox | Yes | Yes | No | Yes |
| Enter, save and submit a manual invoice, and change its lines | Yes | Yes | Draft and Unapproved manual invoices | No |
| Approve, reject, cancel or unapprove an invoice | Yes | Yes | No | No |
| Duplicate or delete an invoice | Yes | Yes | No | No |
| Export an invoice's group summary | Yes | Yes | No | Yes |
| View and export the flat price conversion and sort code tables | Yes | Yes | No | Yes |
| Add, change and delete flat price conversions and sort codes | Yes | No | No | No |
| Run reports R06 to R13 | Yes | Yes | No | Yes |
| Upload an XML file for a client | Yes | Yes | No | Yes |
| Submission History | Yes | Yes | No | Yes |

Industry users have the **Submitter** role. They upload files and see
Submission History only for their own forest clients.

## Getting a role

Ask the CSP application administrator.
